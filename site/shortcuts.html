DONUTSMP SHORTCUTS · VERSION 1.1.0

Four commands.
Four key presses.

Every shortcut sends its command once per press. Each has its own local cooldown and can be rebound in Minecraft’s Controls menu.

/rtpq

Request a random teleport queue.

R

/spawn

Return to the server spawn point.

F6

/ah

Open the auction house.

F7

/shop

Open the server shop.

F8

Server aliases and availability can change. The defaults are configurable in .minecraft/config/rtpq.properties. These are regular client commands; nothing auto-repeats, bypasses server rules, or depends on private server messages.
